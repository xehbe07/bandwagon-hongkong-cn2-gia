## 搬瓦工香港主機現在是什麼配置？

目前的答案是：AMD EPYC 9004 處理器、DDR5 記憶體、NVMe SSD RAID-10 陣列，部署在編號 HKHK_8 的機房，位於香港 Equinix HK2 資料中心。這輪硬體升級在 2024 到 2025 年間完成，第三方測評的 FIO 4K 數據為讀取約 197MB/s、寫入約 198MB/s，IOPS 在 49K 上下，跑資料庫和高併發應用沒有壓力。
